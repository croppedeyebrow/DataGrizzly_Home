ADR-01: 실험실을 프로젝트 과정 기록으로 통합. ADR-02: DB 기반 CMS 유지. ADR-03: 정적 공개와 코드/콘텐츠 배포 분리. ADR-04: PostgreSQL 검색 유지·생성 제외. ADR-05: Rust CLI/WASM·Go CLI. ADR-06: 단일 서버와 외부 백업. ADR-07(종료): Python 제외. ADR-08(현재): Python 문서 워크플로만 추가; [[SCOPE_v5]] 참조.
