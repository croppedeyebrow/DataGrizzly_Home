# v3.0 변경 내용

- 제품 범위·언어 역할은 v2.0 유지.
- 도구 미설치부터 시작하는 S00~S19 추가.
- 기존32개 태스크를 파일·계약·세부 수행·단계 결과·검증·실패 대응까지 확장.
- PowerShell/Ubuntu Bash, 실행 위치, 버전 변수, 명령 존재 시점을 구분.
- M0-03의 DB 검증을 bootstrap migration으로 한정; 업무 schema는 M2-01.
- 초기CI S19와 운영CI/CD M6 분리.
- 기존 총 개발일 추정은 초기환경 설치·학습 시간을 포함하지 않음. 새 작업량 기준으로 착수 후 재산정 필요.
- 기존 PDF v2.0은 제품 개요 참고용. 개발 실행 순서와 상세 절차는 이 MD v3.0을 사용.

## 검증 범위

문서의 내부 링크, 태스크 수, 선행 ID 존재, 단계 순환 여부, ZIP 구성을 검사합니다. 사용자 PC에서 실제 설치·제품 실행을 한 결과물은 아닙니다. 따라서 문서의 체크리스트는 모두 미착수 상태입니다.
