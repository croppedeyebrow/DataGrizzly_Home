## 현장의 데이터에서, 신뢰할 수 있는 시스템까지

개발과 과학을 공부하고, 프로젝트를 구현하며, 설계 판단과 검증 근거를 축적하는 개인 엔지니어링 홈페이지입니다. 홈페이지 자체도 CMS·검색·운영 도구를 직접 개발한 프로젝트로 기록합니다.

## 이번 개정의 확정 방향

실험실 메뉴를 제거합니다. 프로젝트를 설명과 과정 기록으로 나눕니다. 웹 기반 관리자 CMS를 유지합니다. Kotlin은 CMS, Rust는 콘텐츠 검증·가공 도구, Go는 필요 시 국소 배포 도구에 사용합니다. Python은 LangChain·LangGraph 기반 자료 수집·검색·검토 워커에 한정합니다.

## 문서 읽는 순서

1부 기획: 2~7쪽. 2부 아키텍처: 8~19쪽. 3부 개발 계획: 20~25쪽. 부록 의사결정·공식 자료: 26쪽. Markdown 원본에는 수정 가능한 Mermaid 다이어그램을 함께 제공합니다.

## 상태와 가정

요구사항을 바탕으로 한 구현 전 설계안입니다. 클라우드 업체·가격·모델·정확한 버전은 미확정입니다. 1인 운영·낮은 초기 트래픽을 가정하며, 출시 기준과 성능 수치는 측정 전 목표입니다.
