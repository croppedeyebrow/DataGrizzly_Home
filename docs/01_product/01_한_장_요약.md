# 01. 한 장 요약

> v5.0 기준: [[SCOPE_v5]] 적용. 주력 Kotlin·Rust·TypeScript·PostgreSQL. LLM·C++ 제외, Go는 국소 배포 도구로 필요할 때만 사용합니다. 로컬 자원은 [[02_RESOURCE_BUDGET]] 참조.
사용자 가치, 필수 범위, 비용 기준

## 핵심 사용자

운영자는 브라우저에서 기록을 작성·수정·발행합니다. 방문자는 프로젝트 전체를 이해하고 과정 기록을 따라 읽습니다. 채용 담당자는 담당 범위·판단·결과를 확인합니다. 학습자는 주제·시리즈·검색으로 기록을 찾습니다.

## 출시의 필수 범위

홈·소개·프로젝트 설명/과정 기록·노트·리서치·탐색, 관리자 로그인·편집·미디어·미리보기·발행·수정 이력, 공개 콘텐츠 검색, 배포 자동화와 외부 백업을 포함합니다.

## 후속 확장

예약 발행과 고급 분류 편의는 CMS 안정화 단계에 추가합니다. PostgreSQL 검색까지 현재 범위에 포함하고 생성형 답변은 제외합니다. Rust WASM은 브라우저 공통 검증이 필요할 때 추가합니다.

## 제외 범위

상시 실험 서버·방문자 코드 실행·Python 상시 범용 API·GPU 상시 운영·Kubernetes·자체 CI/CD 플랫폼·LLM 사전학습은 초기 범위에서 제외합니다. 기존 실험 기록은 프로젝트의 검증 과정 글로 수용합니다.

## 성공 기준

직접 포스팅할 수 있고, 설명에서 과정 기록과 근거로 이동할 수 있어야 합니다. 공개 웹은 API 장애에도 읽혀야 하며 초안은 검색·AI에 유출되지 않아야 합니다. 생성형 답변이 꺼져도 검색은 사용 가능해야 합니다.
