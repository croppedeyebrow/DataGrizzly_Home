# 04. 관리자 CMS 기능

> v5.0 기준: [[SCOPE_v5]] 적용. 주력 Kotlin·Rust·TypeScript·PostgreSQL. LLM·C++ 제외, Go는 국소 배포 도구로 필요할 때만 사용합니다. 로컬 자원은 [[02_RESOURCE_BUDGET]] 참조.
기존 상세 페이지 디자인으로 직접 작성·발행

## 관리 화면

/admin/login, 관리 홈, 게시물 목록, 작성/수정, 미리보기, 프로젝트, 분류·시리즈, 미디어, 수정 이력, 발행 작업, 검색 상태, 사이트 설정을 구성합니다. 공개 방문자의 회원가입은 요구하지 않습니다.

## 본문 편집

문단·제목·목록·인용·표·이미지/캡션·코드/언어/파일명·LaTeX·요약/주의/해석 상자·관련 글 카드를 제공합니다. 직접 실행 코드나 자유로운 MDX 평가는 허용하지 않습니다. 공개 렌더러와 미리보기는 같은 블록 규격을 사용합니다.

## 콘텐츠별 입력

프로젝트 설명에는 목적·담당 범위·진행 상태·링크를, 과정 기록에는 프로젝트·단계·관련 커밋을 추가합니다. 논문에는 저자·연도·원문 식별자, 뉴스에는 출처·발표일·사건일을 넣습니다. 필수 항목과 선택 항목을 명확히 구분합니다.

## 작성 UX

자동 저장 상태를 저장 중/완료/실패로 표시합니다. 실패 시 편집 내용을 유지하고 재시도합니다. 다른 탭의 버전과 충돌하면 덮어쓰지 않고 비교·선택을 안내합니다. 모바일 미리보기와 페이지 이탈 시 미저장 경고를 제공합니다.

## 백업·내보내기

DB가 콘텐츠 원본입니다. Markdown은 이동용 내보내기이며 블록 JSON과 첨부 매핑을 함께 보존합니다. 모든 블록을 Markdown으로 완벽히 왕복 변환한다고 보장하지 않습니다.

## v5.0 자료 워크플로 반영

관리자 메뉴에 자료 가져오기를 추가합니다. [[A13]] 등록, [[A14]] 작업, [[A15]] 검토. 승인과 기존 공개 발행을 분리합니다.
