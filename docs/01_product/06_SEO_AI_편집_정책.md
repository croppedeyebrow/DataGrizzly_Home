# 06. SEO·AI·편집 정책

> v5.0 기준: [[SCOPE_v5]] 적용. 주력 Kotlin·Rust·TypeScript·PostgreSQL. LLM·C++ 제외, Go는 국소 배포 도구로 필요할 때만 사용합니다. 로컬 자원은 [[02_RESOURCE_BUDGET]] 참조.
검색과 답변은 공개 원문으로 돌아가는 통로

## SEO 기본

초기 HTML에 본문·제목·링크를 포함합니다. 고유 URL·canonical·메타 설명·대표 이미지·사이트맵·RSS·작성자·수정일·적절한 구조화 데이터를 공개본 기준으로 생성합니다. URL 변경은 리디렉션 표로 관리합니다.

## 작성자 신뢰

작성자는 DataGrizzly로 통일하고 실제 이력은 확인된 사실만 씁니다. 논문 저자의 주장, 개인 해석, 재현한 결과를 구분합니다. 뉴스는 원문 링크와 날짜를 남기고 원문 전체를 복제하지 않습니다.

## AI 외부 노출

일반 검색과 AI 검색에 읽을 수 있는 문서·출처·내부 링크를 제공합니다. 노출·인용은 보장되지 않습니다. 검색 수집과 모델 학습 수집 정책은 별도 결정하며 기존 공식 자료 확인일은 2026.10.20입니다.

## 내부 검색·답변 UX

검색 결과는 제목·요약·근거 문단·원문 절 링크를 보여줍니다. 생성형 답변은 제공하지 않습니다. 결과가 없거나 검색이 지연되면 재검색 안내를 제공합니다.

## 측정

검색어의 결과 없음 비율, 검색 결과 클릭, 과정 기록 이동, GitHub·연락처 이동을 관측합니다. 원문 검색어 로그는 기본 비저장 또는 짧은 보존 정책을 적용하고 민감 입력을 수집하지 않도록 안내합니다.
