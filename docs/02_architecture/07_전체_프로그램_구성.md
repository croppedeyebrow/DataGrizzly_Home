# 전체 프로그램 구성 — v5.0

> v5.0 기준: [[SCOPE_v5]] 적용. 주력 React·TypeScript·Tailwind·Rust·PostgreSQL. LLM·C++ 제외, Go는 국소 배포 도구로 필요할 때만 사용합니다. 로컬 자원은 [[02_RESOURCE_BUDGET]] 참조.
React·TypeScript·Tailwind는 공개 웹과 관리자, Rust는 업무 API와 콘텐츠 검증·정규화·절 추출·export, PostgreSQL은 원본·관계·발행 상태·공개 검색 데이터를 담당합니다.

상시 운영 프로세스는 Rust API와 PostgreSQL이며 공개 HTML은 CDN에서 제공합니다. 콘텐츠 검증은 같은 Rust 워크스페이스의 라이브러리가 맡습니다. Go는배포에서구체적필요가있을때만작은도구로사용합니다. C++/LLM은 제외하고 Python은 M8 자료 처리 워커로 추가합니다.
