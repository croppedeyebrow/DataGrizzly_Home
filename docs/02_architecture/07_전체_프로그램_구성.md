# 전체 프로그램 구성 — v5.0

> v5.0 기준: [[SCOPE_v5]] 적용. 주력 Kotlin·Rust·TypeScript·PostgreSQL. LLM·C++ 제외, Go는 국소 배포 도구로 필요할 때만 사용합니다. 로컬 자원은 [[02_RESOURCE_BUDGET]] 참조.
TypeScript(Astro/React)는공개웹·관리자, Kotlin은CMS·인증·발행·검색API, Rust는콘텐츠검증·정규화·절추출·export, PostgreSQL은원본·관계·발행상태·공개검색데이터를담당합니다.

상시운영프로세스는Kotlin과PostgreSQL중심이며공개HTML은CDN에서제공합니다. Rust는작업시에실행하는CLI입니다. Go는배포에서구체적필요가있을때만작은도구로사용합니다. C++/LLM은 제외하고 Python은 M8 자료 처리 워커로 추가합니다.
