# 08. 프론트엔드 구조

> v5.0 기준: [[SCOPE_v5]] 적용. 주력 Kotlin·Rust·TypeScript·PostgreSQL. LLM·C++ 제외, Go는 국소 배포 도구로 필요할 때만 사용합니다. 로컬 자원은 [[02_RESOURCE_BUDGET]] 참조.
공개 웹과 편집 화면을 독립적으로 구성

## 공개 웹: Astro

홈·프로젝트·과정 기록·노트·리서치는 정적으로 생성합니다. React는 검색·모바일 메뉴 등 필요한 상호작용에 사용합니다. HTML/CSS와 웹용 TypeScript를 기본 제안으로 두며 구체 버전은 착수 시 고정합니다.

## 관리자: React

로그인·목록·편집·미디어·발행 상태 화면을 별도 빌드합니다. CMS API를 호출하고 화면 상태와 서버 저장 상태를 구분합니다. 블록 편집기 제품은 문서 스키마·수식·코드·라이선스를 기준으로 선정합니다.

## 공유 패키지

design-tokens, content-schema, block-renderer, api-client를 공유합니다. public의 구조화 데이터·메타 생성은 편집 UI와 분리합니다. 미리보기는 인증 API에서 초안을 받아 같은 block-renderer로 표시하되 캐시·색인을 차단합니다.

## Rust WASM 연동

공통 문서 구조 검사·제목 추출이 필요한 화면에만 로드합니다. WASM 불가 시 작성 화면을 막지 않고 서버 검증으로 이어갑니다. 브라우저 결과를 신뢰해 인증·최종 검증을 생략하지 않습니다.

## 페이지 변경 체크

프로젝트 설명과 과정 목록은 같은 프로젝트 헤더를 공유합니다. 과정 상세에는 프로젝트로 돌아가기·이전/다음 과정·관련 노트를 제공합니다. 기존 실험실 링크와 라우트는 제거하거나 실제 대체 글이 있는 경우에만 이전합니다.
