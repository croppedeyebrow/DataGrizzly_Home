# 09. Kotlin 백엔드 구조

> v5.0 기준: [[SCOPE_v5]] 적용. 주력 Kotlin·Rust·TypeScript·PostgreSQL. LLM·C++ 제외, Go는 국소 배포 도구로 필요할 때만 사용합니다. 로컬 자원은 [[02_RESOURCE_BUDGET]] 참조.
모듈형 단일 애플리케이션을 기본으로 시작

## 모듈 책임

identity: 관리자 인증·세션. content: Entry·Revision·블록. project: 프로젝트와 과정 연결. taxonomy: 태그·주제·시리즈. media: 업로드·사용처. publication: 작업·스냅샷·결과. discovery: PostgreSQL 공개 검색. audit: 작업 이력.

## 계층과 트랜잭션

HTTP 어댑터 → 응용 서비스 → 도메인 규칙 → 저장소/외부 어댑터로 구성합니다. 초안 저장과 발행 접수는 짧은 DB 트랜잭션입니다. 외부 빌드·추론을 트랜잭션이나 요청 스레드에서 오래 기다리지 않습니다.

## 발행 전달

요청 저장과 작업 생성은 같은 DB 트랜잭션에 넣습니다. 소규모 폴러가 커밋된 작업을 전달하며 lease·시도 횟수·재시도 시각을 관리합니다. 전달은 중복될 수 있음을 전제로 작업 키와 세대 번호로 처리합니다. Kafka는 초기 필수가 아닙니다.

## 인증과 권한

1인 소유자만 허용하는 계정 정책을 둡니다. 인증 제공자 기반 로그인 또는 안전한 로컬 인증 중 배포 조건에 맞춰 선정합니다. 세션은 HttpOnly·Secure 쿠키, 관리 요청은 CSRF 방어, 각 리소스는 서버 권한 검사를 적용합니다.

## 검색과 생성 분리

검색 API는 모델 없이 실행됩니다. 질문 생성 API는 구현하지 않습니다. 검색 요청 길이·결과 수·실행 시간을 제한합니다.
