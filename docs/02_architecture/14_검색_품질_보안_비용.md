# 14. 검색 품질·보안·비용

> v5.0 기준: [[SCOPE_v5]] 적용. 주력 Kotlin·Rust·TypeScript·PostgreSQL. LLM·C++ 제외, Go는 국소 배포 도구로 필요할 때만 사용합니다. 로컬 자원은 [[02_RESOURCE_BUDGET]] 참조.
30문항한국어평가와공개세대/철회검증을수행합니다. Recall@5 80%, p951초는목표이며달성값이아닙니다. 실제데이터량·쿼리·CPU/RAM·실행계획을기록합니다. 쿼리는파라미터바인딩하며길이·결과수·timeout을제한합니다.

LLM과생성캐시는없습니다. 공개검색은DB/API만추가부하를발생시키며별도검색서버메모리를요구하지않습니다. 비용감소를금액으로보장하지않고M6실측을사용합니다. 운영서버크기를노트북RAM에맞춰고정하지않습니다.
