# F02 프로젝트 설명과 과정기록

> v5.0 기준: [[SCOPE_v5]] 적용. 주력 Kotlin·Rust·TypeScript·PostgreSQL. LLM·C++ 제외, Go는 국소 배포 도구로 필요할 때만 사용합니다. 로컬 자원은 [[02_RESOURCE_BUDGET]] 참조.
상태: 설계 / 구현 전. 기준: DataGrizzly v2.0. 세부 보완은 본 문서 세트 v2.1에서 제안합니다.

## 사용자와 범위

공개 방문자 및 콘텐츠 작성자가 사용하는 기능입니다. 아래 수용 조건을 구현 단위로 사용합니다.

## 화면·접점

`/projects /projects/{slug} /projects/{slug}/logs /logs/{slug}`

## 데이터·계약

Project, Entry, ProjectLog: projectId, stage, displayOrder, commitUrl

## 수용 조건

- 설명과 과정 탭 공유
- 과정 상세에서 프로젝트 복귀·이전/다음 이동
- 작성일과 읽는 순서 분리

## 실패·보안·운영 조건

비공개 과정은 목록·이전/다음에서 제외; 중복 순서는 정렬 보조키로 일관되게 처리

## 구현 시 검증

정상 입력, 비어 있는 데이터, 실패 상태를 각각 확인합니다. 인증·발행·파일·검색 경계를 변경하면 비공개 데이터의 익명 접근 및 재노출을 함께 검증합니다. 화면 캡처만으로 서버 권한과 데이터 보존 검증을 대체하지 않습니다.
