# F03 학습노트 논문 뉴스

> v5.0 기준: [[SCOPE_v5]] 적용. 주력 Kotlin·Rust·TypeScript·PostgreSQL. LLM·C++ 제외, Go는 국소 배포 도구로 필요할 때만 사용합니다. 로컬 자원은 [[02_RESOURCE_BUDGET]] 참조.
상태: M1-03에서 노트 목록·상세와 리서치 목록·상세를 정적 페이지로 연결했다. 코드와 수식은 실행하지 않는다. 주제 필터와 API는 아직 없다. 기준: DataGrizzly v2.0. 세부 보완은 본 문서 세트 v2.1에서 제안합니다.

## 사용자와 범위

공개 방문자 및 콘텐츠 작성자가 사용하는 기능입니다. 아래 수용 조건을 구현 단위로 사용합니다.

## 화면·접점

`/notes /notes/{slug} /research /research/{slug}`

## 데이터·계약

Entry.type, body, sourceUrl, authors, publicationDate, eventDate

## 수용 조건

- 학습 노트는 프로젝트 없이 작성 가능
- 논문 주장·개인 해석·재현 결과 구분
- 뉴스 사건일과 발표일 분리

## 실패·보안·운영 조건

원문 부재는 명시; 원문 전체 복제 금지; 출처 URL을 실행 가능한 코드로 처리하지 않음

## 구현 시 검증

정상 입력, 비어 있는 데이터, 실패 상태를 각각 확인합니다. 인증·발행·파일·검색 경계를 변경하면 비공개 데이터의 익명 접근 및 재노출을 함께 검증합니다. 화면 캡처만으로 서버 권한과 데이터 보존 검증을 대체하지 않습니다.
