# F13 C++ 근거검색

상태: 설계 / 구현 전. 기준: DataGrizzly v2.0. 세부 보완은 본 문서 세트 v2.1에서 제안합니다.

## 사용자와 범위

공개 방문자 및 콘텐츠 작성자가 사용하는 기능입니다. 아래 수용 조건을 구현 단위로 사용합니다.

## 화면·접점

`GET /api/search`

## 데이터·계약

query, type, project, releaseId; hits with entry/revision/chunk IDs

## 수용 조건

- 모델 없이 검색 가능
- 검색 hit의 공개 상태 재검사
- 원문 절 링크 제공
- 30문항 Recall@5 평가

## 실패·보안·운영 조건

손상 인덱스 거부; 철회 ID 제외; score를 확률처럼 표시하지 않음; 실제 실패와 결과 없음 분리

## 구현 시 검증

정상 입력, 비어 있는 데이터, 실패 상태를 각각 확인합니다. 인증·발행·파일·검색 경계를 변경하면 비공개 데이터의 익명 접근 및 재노출을 함께 검증합니다. 화면 캡처만으로 서버 권한과 데이터 보존 검증을 대체하지 않습니다.
