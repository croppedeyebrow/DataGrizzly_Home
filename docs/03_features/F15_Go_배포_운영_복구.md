# F15 Go 배포 운영 복구

상태: 설계 / 구현 전. 기준: DataGrizzly v2.0. 세부 보완은 본 문서 세트 v2.1에서 제안합니다.

## 사용자와 범위

관리자·운영자가 사용하는 기능입니다. 아래 수용 조건을 구현 단위로 사용합니다.

## 화면·접점

`CLI dgops / CI workflows`

## 데이터·계약

image digest, release manifest, backup metadata, health result

## 수용 조건

- 같은 이미지 승격
- JSON 출력·종료 코드
- 격리 환경 복원 검증
- 예산·디스크 알림

## 실패·보안·운영 조건

단일 서버 장애 위험 수용; 예산 알림은 자동 비용 차단 아님; 데이터 마이그레이션은 이미지 rollback과 별도 판단

## 구현 시 검증

정상 입력, 비어 있는 데이터, 실패 상태를 각각 확인합니다. 인증·발행·파일·검색 경계를 변경하면 비공개 데이터의 익명 접근 및 재노출을 함께 검증합니다. 화면 캡처만으로 서버 권한과 데이터 보존 검증을 대체하지 않습니다.
