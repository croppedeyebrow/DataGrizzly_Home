# F16 자료 수집·검토·초안 생성

사용자는 관리자에서 자료를 등록하고 처리 상태를 확인한 후 메타데이터·발췌·관련 글을 검토합니다. 승인하면 기존 CMS에 초안을 생성합니다. 생성형 모델은 사용하지 않습니다.

입력: 텍스트 PDF·Markdown, 보안 게이트 후 URL. 출력: 출처가 있는 검토 자료와 CMS 초안. 화면 [[A13]], [[A14]], [[A15]]. 구현 [[WF08_TASK_MAP]].

수용 조건: 재시작 후 검토 복구, 승인 중복 시 초안 한 개, 원문 비공개, 거절·취소 추적, Python 없이 기존 사이트 정상. 자세한 상태/API/보안은 [[WF03_STATE_MACHINE]], [[WF04_DATA_API]], [[WF05_SECURITY_LIMITS]]를 따릅니다.
