## 세부 구현 작업

### M0-02.01 — 블록 식별자와 버전 작성

- **할 일:** 문단/제목/목록/인용/표/이미지/코드/수식/콜아웃/관련글의 type별 필수 필드를 정합니다. 스크립트와 임의 MDX는 허용하지 않습니다.
- **단계 완료 결과:** 지원되지 않은 type/schemaVersion fixture가 실패함
- **기록:** 변경 파일과 이 조건을 확인한 명령/관측값을 작업 기록에 남깁니다.

### M0-02.02 — Entry와 Revision 분리

- **할 일:** Entry identity·slug·type·draft/published pointer·version, Revision immutable body·metadata·schemaVersion을 정의합니다. 날짜는 UTC ISO8601로 교환합니다.
- **단계 완료 결과:** 수정본 내용과 공개 포인터가 혼동되지 않음
- **기록:** 변경 파일과 이 조건을 확인한 명령/관측값을 작업 기록에 남깁니다.

### M0-02.03 — API 실제 명세 작성

- **할 일:** 공통 오류 code/message/requestId/fieldErrors, 인증,409/422/429, idempotency key, pagination과 길이 상한을 OpenAPI로 작성합니다.
- **단계 완료 결과:** 명세 lint와 예제 validation 통과
- **기록:** 변경 파일과 이 조건을 확인한 명령/관측값을 작업 기록에 남깁니다.

### M0-02.04 — 교차언어 fixture 확정

- **할 일:** 정상·누락·unknown block·중복 anchor·잘못된 projectId 예제를 만듭니다. DB 참조 검증과 JSON 구조 검증을 구분합니다.
- **단계 완료 결과:** JSON만으로 DB 존재를 검증했다고 주장하지 않음
- **기록:** 변경 파일과 이 조건을 확인한 명령/관측값을 작업 기록에 남깁니다.

### M0-02.05 — 생성자와 소비자 합의

- **할 일:** Kotlin/TS/Rust가 같은 fixture를 사용할 경로를 고정합니다. 스키마 변경은 migration/지원 버전 정책과 함께 기록합니다.
- **단계 완료 결과:** 모든 예제에 schemaVersion 존재
- **기록:** 변경 파일과 이 조건을 확인한 명령/관측값을 작업 기록에 남깁니다.

## 입력·오류·경계 검증

정상 예제 통과, 필수 필드 누락 거부, 허용하지 않은 URL scheme 거부, 오류 위치의 JSON path를 확인합니다.

정상 케이스만 확인하지 않습니다. 입력이 잘못된 경우, 선행 자원이 없는 경우, 관련 외부 컴포넌트가 실패한 경우를 구분합니다. 실제 실패 주입이 불가능하면 미실행으로 적고 실행 환경을 명시합니다.

## 실행 방법과 증거

[명령 계약](../00_guide/COMMANDS.md)의 해당 구성요소 검사부터 실행합니다. 기능 테스트가 아직 없으면 이 태스크의 위험을 검증하는 테스트를 작성한 뒤 실제 명령을 기록합니다. 빌드 성공은 기능 수용조건 충족과 별개입니다.

| 검증 구분 | 확인 대상 | 남길 증거 |
|---|---|---|
| 계약 | 연결 기능 명세·schema·API 응답 | 입력/응답 예제, schema 검증 결과 |
| 정상 동작 | 위 세부 작업의 완료 결과 | 테스트 이름·실행 명령·결과 |
| 실패 동작 | 위 경계·오류 시나리오 | 재현 절차·오류코드·상태 보존 결과 |
| 회귀 | 영향을 받은 기존 공개/관리 흐름 | 관련 테스트 결과·변경 전후 차이 |

## 실패 시 복구·중단 기준

- 파일/명령 없음: 아직 산출물을 생성하지 않았는지 먼저 확인합니다. 가짜 성공 스크립트로 통과시키지 않습니다.
- 계약과 코드 불일치: producer/consumer/fixture를 함께 검토하고 schemaVersion 변경 필요성을 기록합니다.
- 데이터 변경 실패: 트랜잭션·migration 이력을 확인합니다. 개발 DB 전체 삭제를 기본 해결법으로 쓰지 않습니다.
- 선행 태스크 결함: 해당 ID와 재현 증거를 남기고 현재 작업 완료를 보류합니다.
- 리소스 부족: 측정값을 남기고 선택 기능을 비활성화합니다. 승인되지 않은 유료 자원을 자동 생성하지 않습니다.
