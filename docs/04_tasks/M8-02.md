- 실패 주입 증거: 이미지 전용 PDF는 `image_only`, 손상 파일은 `damaged`, 암호화 PDF는 `encrypted`, 10MiB 초과와 101페이지는 성공 파일 없이 거절된다. 100만 자 초과는 Rust가 `too_many_chars`를 반환하고 부분 결과를 만들지 않는다. timeout은 해당 작업 디렉터리만 지운다. 다른 결과 hash는 `artifact_conflict`이며 기존 artifact는 유지된다.

- 미검증/차단 사항: 브라우저에서 script 실행 여부를 열지는 않았다. 정규화 결과는 script 문장을 텍스트로 남긴다. OCR과 모델 호출은 넣지 않았다.
