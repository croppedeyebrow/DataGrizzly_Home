## 세부 작업

### M8-05.01 claim·heartbeat

DB 행 잠금으로 작업 하나를 claim하고 lease token을 발급합니다. 회수된 작업에 옛 워커가 쓰면 409를 반환합니다.

산출물: 해당 코드·계약·fixture와 검증 결과를 같은 변경에 포함합니다. 선행 단계 실패 시 다음 단계로 넘기지 않습니다.

### M8-05.02 승인 접수
