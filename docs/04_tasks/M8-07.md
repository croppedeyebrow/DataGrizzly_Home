### M8-07.02 네트워크 통제

산출물: 해당 코드·계약·fixture와 검증 결과를 같은 변경에 포함합니다. 선행 단계 실패 시 다음 단계로 넘기지 않습니다.

### M8-07.03 응답 제한

연결/읽기 timeout·스트리밍 bytes·압축 해제 후 크기를 제한합니다. 사용자 credential이나 내부 API header를 전달하지 않습니다.
