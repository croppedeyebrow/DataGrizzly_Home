## 상세 수행

### S09.01

루트 `package.json`은 `private: true`이며 Yarn 버전을 `packageManager`에 고정합니다. 최초 workspace는 S10에서 생성할 `apps/web`만 포함합니다.

### S09.02

S10 생성기는 install/Git init을 건너뛰고 루트에서 Yarn install을 한 번 실행합니다. lockfile은 루트 `yarn.lock` 하나만 유지합니다.

### S09.03

관리자와 공통 패키지는 실제 작업 시 workspace에 추가합니다. 이름은 `@datagrizzly/web`와 `@datagrizzly/admin`을 유지합니다.

### S09.04

`.yarnrc.yml`은 일반 `node_modules` 호환 방식을 사용하면서 제3자 설치 스크립트를 기본 차단합니다. Hardened Mode와 3일 age gate를 적용하며, 필요한 설치 스크립트는 패키지를 검토한 뒤 개별 허용합니다.
