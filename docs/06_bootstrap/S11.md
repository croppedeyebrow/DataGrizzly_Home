## 명령과 산출물

파일 생성·선행조건 확인 후 실행합니다. 주석 처리된 설치 명령과 버전 자리표시는 AI가 실제 선택값으로 채워 별도 실행 블록으로 제시합니다.

```powershell
corepack yarn dlx create-vite@9.3.1 apps/admin --template react-ts
# package.json의 workspaces에 apps/admin을 추가한 뒤 실행
corepack yarn install
corepack yarn install --immutable
corepack yarn workspace @datagrizzly/admin build
corepack yarn workspace @datagrizzly/admin dev --host 127.0.0.1 --port 5173
```

산출물: `apps/admin/**`
