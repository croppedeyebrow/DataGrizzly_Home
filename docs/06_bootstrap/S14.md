## 상세 수행

### S14.01

이 항목은 보류다. 접속은 Rust와 SQLx가 `DB_URL`, `DB_USER`, `DB_PASSWORD`를 프로세스 환경에서 읽는다. JDBC와 Flyway는 추가하지 않는다.

### S14.02

V1은연결검증용schema/메타만생성합니다. 업무테이블은M2-01입니다.

### S14.03

연결 풀은 최대 4, idle 1부터 실측합니다. 프레임워크가 `.env`를 자동으로 읽는다고 가정하지 않습니다. 비밀값은 프로세스 환경으로만 넣습니다.

## 명령과 산출물

파일 생성·선행조건 확인 후 실행합니다. 주석 처리된 설치 명령과 버전 자리표시는 AI가 실제 선택값으로 채워 별도 실행 블록으로 제시합니다.

이 명령은 실행하지 않는다. 같은 역할의 다음 작업은 `services/api`에서 Rust로 데이터베이스에 접속하는 것이다. 비밀번호는 `.env`에만 두고 저장소와 로그에 남기지 않는다.

산출물 예정: Rust 메타 마이그레이션. JDBC URL과 Flyway 파일은 만들지 않는다.
