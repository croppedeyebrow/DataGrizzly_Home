## 명령과 산출물

파일 생성·선행조건 확인 후 실행합니다. 주석 처리된 설치 명령과 버전 자리표시는 AI가 실제 선택값으로 채워 별도 실행 블록으로 제시합니다.

```powershell
$env:DB_URL="jdbc:postgresql://localhost:15432/datagrizzly"
$env:DB_USER="datagrizzly"
# DB_PASSWORD는 로컬에서 안전하게 입력/주입한 뒤 실행
Set-Location C:\Dev\sideproject\My_Web\services\cms
.\gradlew.bat bootRun --args="--spring.profiles.active=local"
```

산출물: `application-local.yml; V1__bootstrap.sql`
