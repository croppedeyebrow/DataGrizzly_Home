# S20 Python 워커 전용 환경 — M8 직전

상태: 미착수. 선행: S00·S05, 기존 M5 검색 동작. 모드: DOCS/단독 설치. [[WF06_OPERATIONS]]

## 시작 전

현재 PC에 Python/uv가 있는지 먼저 확인합니다. 없다고 가정하고 중복 설치하지 않습니다. 새 가상환경과 캐시가 디스크 여유 정책을 만족하는지 확인합니다. 시스템 Python·다른 프로젝트 venv는 변경하지 않습니다.

```powershell
Get-Command uv, python, py -ErrorAction SilentlyContinue
py -0p
uv --version
Get-PSDrive C
```

명령이 없으면 해당 도구 미설치로 기록합니다. uv 공식 설치 문서의 Windows 방법을 확인해 사용자 범위로 설치하고 새 PowerShell에서 확인합니다. Python은 3.12 계열을 시작 후보로 삼되 선택 패키지 호환 확인 후 patch 버전을 versions.md에 기록합니다. 3.12가 없다면 uv python install 3.12로 설치할 수 있으며 먼저 디스크를 확인합니다.

## 생성 순서

저장소 루트 C:\Dev\sideproject\My_Web에서 workers/document-workflow가 없는지 확인합니다. 이미 있으면 init을 반복하지 않고 기존 pyproject를 읽습니다.

```powershell
uv init --package --python 3.12 workers/document-workflow
Set-Location workers/document-workflow
uv add langgraph langchain-core httpx pydantic pypdf
uv add --dev pytest ruff mypy
uv run python --version
uv run python -c "import langgraph, langchain_core, pypdf; print('imports OK')"
```

프로젝트 패키지 경로를 src/dg_workflow로 정리하고 cli.py의 main과 pyproject script entry를 연결합니다. 기본 생성 sample은 확인 후 교체합니다. .venv·.env·비공개 자료·local checkpoint를 Git에서 제외하고 pyproject.toml·uv.lock·.python-version을 커밋합니다. langchain 전체·community 전체가 필요한지는 먼저 의존성 크기를 확인합니다. pypdf+자체 BaseLoader 어댑터로 시작할 수 있습니다.

## 확인·복구

uv run pytest가 빈 테스트 통과를 의미하지 않도록 import smoke 하나를 작성합니다. uv sync --locked 재현을 확인합니다. 실패하면 오류·Python 버전·lock을 기록하고 임의 전체 업그레이드를 하지 않습니다. 제거가 필요하면 이 프로젝트의 .venv만 대상으로 삼고 원본 자료/다른 venv는 건드리지 않습니다.
