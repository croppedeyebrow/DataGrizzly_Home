# S22 워커 실행 골격·Rust 연결·기본 CI

상태: 미착수. 선행: [[S21]], M4 Rust CLI. 아직 실제 자료 워크플로는 M8에서 구현합니다.

1. cli.py에 --once/--drain/--job 인자와 명확한 종료 코드를 정의합니다. 작업 없음은 정상 종료입니다.
2. 환경 누락은 실행 시작 전에 실패시키고 secret을 출력하지 않습니다. 로컬 Kotlin 내부 API 주소를 공개 URL과 구분합니다.
3. Rust CLI 계약 버전 확인 명령을 만들고 OS별 실행 어댑터를 분리합니다. Windows에서는 WSL Rust 바이너리에 JSON stdin을 넘기는 smoke 테스트를 수행합니다. WSL 경로를 Windows 파일 경로로 추정하지 않습니다.
4. 작은 합성 문서 하나를 입력해 stdout JSON schema와 종료 코드를 검사합니다. timeout/오류시 임시 파일만 정리합니다.
5. ruff·mypy·pytest 설정을 만들고 Python 경로 변경 시에만 실행하는 CI job을 추가합니다. CI는 lock 기반 설치, 외부 live fetch 없음, 비밀 없는 fixture만 사용합니다.
6. workers/document-workflow에서 `uv run python -m dg_workflow.cli --help`, `uv run ruff check .`, `uv run mypy src`, `uv run pytest`를 실행합니다. 각 명령은 해당 코드/설정 생성 후 실행합니다.

완료 조건: 실제 help 출력, fixture 처리 결과, CI 기록, 재현 가능한 lock, Rust 버전/계약 일치. 새 워커를 기본 compose 상시 서비스로 추가하지 않습니다.
