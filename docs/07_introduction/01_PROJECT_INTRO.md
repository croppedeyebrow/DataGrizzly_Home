# 개발 개요와 프로젝트 소개

> v5.0 기준: [[SCOPE_v5]] 적용. 주력 Kotlin·Rust·TypeScript·PostgreSQL. LLM·C++ 제외, Go는 국소 배포 도구로 필요할 때만 사용합니다. 로컬 자원은 [[02_RESOURCE_BUDGET]] 참조.
DataGrizzly — 현장의 데이터에서, 신뢰할 수 있는 시스템까지.

## 무엇을 만드는가

개발자 소개, 프로젝트 설명과 과정 기록, 독립적인 공부 기록, 논문·도메인 뉴스 정리를 한곳에 축적하는 개인 엔지니어링 홈페이지입니다. 작성자는 브라우저에서 직접 글을 작성·발행하고, 방문자는 프로젝트 결과와 그 과정의 판단 근거를 함께 읽습니다.

## 왜 만드는가

외부 SNS에 흩어진 콘텐츠의 구조와 표현을 직접 관리하고, 산업 데이터·백엔드·운영·AI 시스템을 향한 커리어 방향을 실제 구현과 검증 기록으로 보여주기 위함입니다. 홈페이지 자체도 CMS·검색·배포·복구를 설계한 포트폴리오 프로젝트로 남깁니다.

## 대상과 제공 가치

| 사용자 | 목적 | 제공 화면 |
|---|---|---|
| 작성자 | 학습과 개발 기록 작성·보존 | CMS·첨부·미리보기·이력·발행 |
| 채용 담당자 | 문제 해결 능력과 담당 범위 확인 | 소개·프로젝트 설명·검증 기록 |
| 개발자·학습자 | 개념·구현 근거 탐색 | 노트·리서치·주제·시리즈·검색 |

## 콘텐츠의 구조

프로젝트 설명은 목적·범위·구조·결과의 전체 지도입니다. 과정 기록은 질문·대안·선택·구현·검증의 이력입니다. 학습 노트는 프로젝트 연결을 강제하지 않습니다. 논문/뉴스에는 원문 출처·사실·개인 해석·재현 여부를 구분합니다.

## 개발 목표와 제외 범위

직접 포스팅, 초안/공개 분리, API 장애 중 정적 읽기, 공개 근거 검색, 배포와 백업 복구를 구현합니다. LLM 답변은 현재 범위에서 제외합니다. 향후 필요하면 Python 기반 별도 실험으로 검토합니다. Python 범용 백엔드, 실험실 실행 화면, 방문자 코드 실행, 초기 상시 GPU·Kubernetes는 제외합니다.

## 현재 상태

기획·개발 지침·화면 설계 단계입니다. 이미지 속 프로젝트·날짜·저장 상태는 예시이며 실제 운영 실적을 뜻하지 않습니다. 기존 브랜드의 문구·콘텐츠 방향을 계승하되 이번 색상/레이아웃은 신규 제안입니다.
