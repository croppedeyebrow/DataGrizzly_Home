# AI에게 화면 구현을 맡기는 방법

> v5.0 기준: [[SCOPE_v5]] 적용. 주력 Kotlin·Rust·TypeScript·PostgreSQL. LLM·C++ 제외, Go는 국소 배포 도구로 필요할 때만 사용합니다. 로컬 자원은 [[02_RESOURCE_BUDGET]] 참조.
1. 현재 태스크의 연결 화면 ID를 확인합니다.
2. 공통 계약과 기능 명세를 읽힌 뒤 09_screen_specs의 해당 문서를 읽힙니다.
3. 같은 ID의 wireframes PNG와 ui PNG를 함께 제공합니다.
4. 모바일은 해당 패턴 이미지와 UI_UX_GUIDE의 축소 규칙을 제공합니다.
5. 실제 코드·컴포넌트 구조를 확인한 뒤 공통 토큰·렌더러를 재사용하게 합니다.
6. 화면의 저장/발행 성공은 실제 API 결과로 연결하고 네트워크 오류·권한·충돌 상태를 검증합니다.

예: M2-02 구현은 A03/A04, F06, 공통 계약, 기존 CMS/편집 코드를 함께 읽힙니다. 이미지에 없는 자세한 에러 동작은 기능 명세를 적용합니다. AI에게 모든 이미지64개를 한꺼번에 입력할 필요는 없습니다.
