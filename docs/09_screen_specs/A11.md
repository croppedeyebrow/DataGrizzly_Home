## 동작·상태 기준

연결 기능 명세의 권한·데이터·오류 계약을 적용합니다. 읽기 화면은 공개 데이터만, 관리 화면은 소유자 인증 이후에 제공합니다. 로딩·빈 데이터·실패 상태를 숨기지 않습니다. 화면의 예시 데이터를 실제 API 응답으로 교체하고 임의의 성공 상태를 하드코딩하지 않습니다.
