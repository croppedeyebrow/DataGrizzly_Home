# A13 자료 등록

버전 v5.0. 경로: `/admin/imports/new`. 권한: 로그인한 관리자·소유 작업만. 구현: [[M8-06]]. API: [[WF04_DATA_API]].

## 화면·행동

상단: 자료 등록 제목과 지원 형식. 본문: 파일 선택(PDF/Markdown), 출처 URL, 제목(선택), 키워드/태그, 처리 한도 안내. 하단: 등록·취소. URL fetch 활성 시 별도 URL 탭을 표시합니다.

등록 버튼은 클라이언트 크기 검사 후 업로드→sourceId→작업 접수를 순서대로 실행합니다. 업로드만 성공하고 작업 접수가 실패하면 sourceId를 재사용해 접수 재시도합니다. 같은 requestId를 유지합니다. 성공 시 A14 상세로 이동하며 ‘초안 생성 완료’로 오표시하지 않습니다.

상태: 빈 화면·선택·업로드 중·접수 중·413/415/422·인증 만료·네트워크 재시도. 원문은 비공개임을 표시하고 서버가 최종 검증합니다.

## 접근성·검증

모든 입력에 label을 제공하고 오류 위치로 focus를 이동합니다. 상태 갱신은 aria-live를 사용하되 polling마다 focus를 빼앗지 않습니다. 키보드만으로 등록·검토가 가능해야 합니다. HTML/Markdown은 sanitize합니다. 정상·빈 결과·대기·실패·권한 없음·충돌·모바일 상태를 fixture로 검증합니다.

## 시각 자료

기존 관리자 디자인 토큰·간격·버튼 규칙을 재사용합니다. 이 신규 화면의 PNG는 아직 제작하지 않았으며 기존 이미지가 이 기능을 표현한다고 가정하지 않습니다.
