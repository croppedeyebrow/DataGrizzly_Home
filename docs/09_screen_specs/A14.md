# A14 가져오기 작업 목록·상세

버전 v5.0. 경로: `/admin/imports`. 권한: 로그인한 관리자·소유 작업만. 구현: [[M8-06]]. API: [[WF04_DATA_API]].

## 화면·행동

목록: 등록 시각, 자료 제목, 형식, 상태, 현재 단계, 최근 갱신 시각. 필터: 전체/대기/처리/검토/실패/완료. 페이지네이션과 상세 링크를 제공합니다.

상세: 단계 타임라인·경고·안전한 오류 이유·허용 action·원문 다운로드·검토 이동·초안 이동. NEEDS_REVIEW에만 검토 버튼, FAILED 중 retryable에 재시도, 종료되지 않은 작업에 취소를 제공합니다. stale version 충돌이면 최신 상태로 갱신합니다.

워커가 꺼져 있으면 ‘실행 대기 — 워커 실행 후 처리됩니다’를 표시합니다. 승인 뒤 RESUME_QUEUED는 ‘승인됨·저장 대기’이며 완료 배지가 아닙니다. 5초 polling은 화면이 활성일 때만 하고 연속 실패 시 backoff·수동 새로고침을 제공합니다.

## 접근성·검증

모든 입력에 label을 제공하고 오류 위치로 focus를 이동합니다. 상태 갱신은 aria-live를 사용하되 polling마다 focus를 빼앗지 않습니다. 키보드만으로 등록·검토가 가능해야 합니다. HTML/Markdown은 sanitize합니다. 정상·빈 결과·대기·실패·권한 없음·충돌·모바일 상태를 fixture로 검증합니다.

## 시각 자료

기존 관리자 디자인 토큰·간격·버튼 규칙을 재사용합니다. 이 신규 화면의 PNG는 아직 제작하지 않았으며 기존 이미지가 이 기능을 표현한다고 가정하지 않습니다.
