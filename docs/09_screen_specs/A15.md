# A15 자료 검토·초안 생성

버전 v5.0. 경로: `/admin/imports/:id/review`. 권한: 로그인한 관리자·소유 작업만. 구현: [[M8-06]]. API: [[WF04_DATA_API]].

## 화면·행동

데스크톱: 왼쪽 원문 발췌·페이지/절 출처, 오른쪽 제목·저자·날짜·DOI·태그·관련 글·직접 코멘트 편집. 모바일: 메타데이터→원문→관련 글→코멘트 순으로 세로 배치합니다.

누락 메타데이터는 ‘미확인’, 중복은 ‘기존 자료 확인’으로 표시합니다. 원문 전체를 기본 공개 초안에 복사하지 않습니다. 사용자가 선택한 발췌와 자신의 해설만 초안으로 전달합니다. ‘자동 요약’이나 ‘AI 답변’ 표현을 사용하지 않습니다.

버튼: ‘승인하고 초안 생성’, ‘거절’, ‘목록으로’. 승인 시 commandId/expectedReviewVersion을 전송하고 승인 후 저장 대기를 안내합니다. 같은 요청 재전송은 같은 commandId입니다. 409면 입력을 보존하고 최신 버전과 비교하도록 안내합니다. 원문 추출이 실패한 상태에서는 승인 버튼을 제공하지 않습니다.

저장 완료 후 기존 CMS 편집기로 연결합니다. 공개 발행 버튼은 이 화면에 두지 않습니다.

## 접근성·검증

모든 입력에 label을 제공하고 오류 위치로 focus를 이동합니다. 상태 갱신은 aria-live를 사용하되 polling마다 focus를 빼앗지 않습니다. 키보드만으로 등록·검토가 가능해야 합니다. HTML/Markdown은 sanitize합니다. 정상·빈 결과·대기·실패·권한 없음·충돌·모바일 상태를 fixture로 검증합니다.

## 시각 자료

기존 관리자 디자인 토큰·간격·버튼 규칙을 재사용합니다. 이 신규 화면의 PNG는 아직 제작하지 않았으며 기존 이미지가 이 기능을 표현한다고 가정하지 않습니다.
