# WF01 개발 개요·사용자 가치

## 문제와 목표

논문·뉴스·학습 자료를 블로그로 옮길 때 출처와 본문을 반복 입력하고, 관련 프로젝트를 다시 찾으며, 실패한 가져오기를 처음부터 반복하는 문제를 줄입니다. 외부 자료를 곧바로 공개하지 않고 검토 가능한 초안으로 만드는 것이 목표입니다.

## 구현 결과

- 관리자가 텍스트 PDF 또는 Markdown을 등록합니다. URL은 보안 게이트 통과 후 추가합니다.
- 추출 가능한 제목·저자·날짜·DOI와 페이지/절별 본문을 제시합니다. 누락값은 미확인으로 표시하고 추측하지 않습니다.
- SHA-256이 같은 원문은 기존 결과를 안내합니다. 유사한 제목만으로 자료를 삭제하지 않습니다.
- 사용자가 선택한 키워드·태그로 공개 검색 API를 조회하고 관련 글을 제안합니다.
- 검토 승인 시 출처, 선택 발췌, 사용자가 쓴 코멘트를 CMS 초안으로 저장합니다. 자동 요약이라고 표시하지 않습니다.
- 실패·대기·취소를 관리 화면에서 확인하고 적합한 지점부터 재개합니다.

## 수용 기준

작업 중 워커가 종료되어도 원본·상태·승인 의도가 남아야 합니다. 같은 승인이나 저장 요청을 반복해도 초안은 하나입니다. 수집 원문과 미검토 결과는 공개 검색·sitemap·RSS에 나오지 않습니다. Python 없이 공개 웹·CMS·검색이 정상 동작합니다.
