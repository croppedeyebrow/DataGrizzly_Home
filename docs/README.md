## 이번 핵심 결정

- Python은 LangChain 문서/검색 어댑터와 LangGraph 처리 흐름만 담당합니다.
- Kotlin이 권한·작업·승인·초안 저장·최종 발행의 기준입니다.
- Rust는 본문 검증·정규화·절 추출을 계속 담당합니다.
- LLM·임베딩·자동 요약·벡터DB·새 broker는 추가하지 않습니다.
- 워커가 꺼져 있어도 승인 의도를 저장하며 재실행 후 처리합니다.
- 새 UI PNG는 제작하지 않았습니다. A13~A15 명세를 기존 디자인에 적용합니다.

## AI에게 전달할 순서

전체 ZIP을 무조건 한 컨텍스트에 넣지 말고 현재 범위, 실행할 태스크, 그 태스크가 연결하는 계약/화면/테스트 문서를 먼저 전달합니다. 작업 완료 시 실제 변경·검증·미실행 항목을 인계 문서에 남깁니다.

변경 내역은 [[CHANGELOG_v5]]를 확인합니다. 각 폴더 첫 목차에서 같은 폴더 문서에 접근할 수 있습니다.
