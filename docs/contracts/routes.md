# 공개·관리 경로

- 확정일: 2026-10-25
- 태스크: M0-01
- 상태: 경로 계약. 공개 웹에는 `/`, `/about`, `/projects`, `/projects/{slug}`, `/projects/{slug}/logs`, `/logs/{slug}`가 있다. 노트·리서치와 관리자 앱은 아직 없다

## 관리자 기준 경로

관리자 운영 경로는 별도 호스트가 아니라 공개 사이트와 같은 출처의 `/admin`이다. 화면 목록과 사이트맵이 이미 이 경로를 쓰고 있다.

| 항목 | 결정 |
|---|---|
| 라우터 base | `/admin` |
| asset base | `/admin/` |
| 로컬 개발 | 관리자 앱이 생긴 뒤 `127.0.0.1:5173`. 공개 웹 개발 서버와 동시에 띄우지 않는다 |
| 운영 출처 | 미정. 도메인과 호스팅은 M6에서 사이트 소유자가 정한다 |

관리자 정적 파일은 `/admin/` 아래에 둔다. 공개 Astro 페이지의 `/` 자산과 섞지 않는다. 로컬 5173은 운영 경로가 아니다.

## 겹침

- 공개 경로는 `/admin`으로 시작하지 않는다. `/admin`은 공개 slug로 잡지 않는다.
- `/projects/{slug}`와 `/logs/{slug}`는 다른 패턴이다. 과정 기록의 canonical은 `/logs/{slug}`이고 `/projects/{slug}/logs/{slug}`는 만들지 않는다.
- P10과 P11은 `/research/{slug}` 하나를 같이 쓴다. 논문과 뉴스는 글 종류로 구분한다.
- `/admin/imports/new`는 고정 경로다. `{id}`보다 먼저 맞춰야 하지만, `{id}`만 있는 페이지 경로는 없다.
- 검색 조건은 `/explore`의 쿼리다. 쿼리 조합을 별도 페이지로 늘리지 않는다.

## 실험실 주소

`/lab`, `/labs`, `/experiments`와 실험 실행·결과 주소는 경로 목록에 없다. 지금 연결할 대체 글도 없다. 그 주소는 404다. 나중에 실제 공개 글이 있을 때만 그 글의 canonical로 연결할 수 있다.

## 아직 아닌 것

이 표는 M1 이후에 공개 페이지로, M2 이후에 관리자 화면으로 구현한다. 인증 제공자와 블록 편집기 제품은 여기서 정하지 않는다. API 필드는 `contracts/openapi.yaml`과 `contracts/content.schema.json`에 있다.
