# 공개·관리 범위

- 확정일: 2026-10-25
- 태스크: M0-01
- 상태: 화면 목록과 미포함 범위의 계약. 페이지 구현이 아님
- 현재 코드: `apps/web`은 홈, 소개, 프로젝트, 과정, 노트, 리서치를 정적 페이지로 만든다. 소개와 연락, GitHub, 주제는 빈 상태다. 탐색과 아래 나머지 경로의 화면은 아직 없다

## 사용자 행동

| 사용자 | 시작 | 행동 | 기대 결과 |
|---|---|---|---|
| 방문자 | `/` | 소개, 프로젝트, 노트, 리서치, 탐색으로 이동한다 | 공개된 글만 읽는다. 계정은 없다 |
| 방문자 | `/projects` | 프로젝트 설명을 연 뒤 그 프로젝트의 과정 목록으로 간다 | 설명과 과정 기록이 구분된다 |
| 방문자 | `/logs/{slug}` | 과정 기록에서 프로젝트로 돌아가거나 관련 노트를 연다 | 비공개 과정은 목록과 이전·다음에 없다 |
| 채용 담당자 | `/` 또는 `/about` | 프로젝트 설명과 과정 기록에서 문제, 선택, 검증을 읽는다 | 방문자와 같은 공개 페이지만 본다. 로그인하지 않는다 |
| 작성자 | `/admin/login` | 글을 저장하고 발행한다 | 초안은 공개 경로에 나오지 않는다. 인증은 M2-01에서 구현한다 |

대표 읽기 순서는 `/` → `/projects/{slug}` → `/projects/{slug}/logs` → `/logs/{slug}` → 관련 `/notes/{slug}`다. 학습 노트는 프로젝트에 연결하지 않아도 된다.

실험실 실행, 실험 결과 화면, 방문자 코드 실행은 행동에 넣지 않는다.

## 이번 출시에 포함하는 화면

공개 화면은 P01~P15, 관리 화면은 A01~A15다. 출처는 `docs/07_introduction/04_SCREEN_CATALOG.md`와 A13~A15 명세다. 경로의 정적·인증·빈 상태·오류·canonical은 `routes.md`에 둔다.

`/explore`는 검색 전용이다. 질문 패널과 `/api/ask`는 포함하지 않는다.

## 제외

| 항목 | 계약 |
|---|---|
| 방문자 회원가입 | 제외. 공개 화면에 가입 경로를 만들지 않는다 |
| 상시 실험 서버 | 제외. 실험 실행 API와 상시 GPU·Kubernetes도 포함하지 않는다 |
| 실험실 경로 | `/lab`, `/labs`, `/experiments`는 정상 경로가 아니다. 대체할 실제 글이 없으므로 404다 |
| M7 생성 | 이번 출시에서 제외. 없어도 공개 출시를 막지 않는다 |
| C++ 검색·추론 서버 | 제외 |

M0-01.03은 M7 생성을 선택 기능으로 적으라고 한다. `docs/00_guide/SCOPE_v5.md`, `docs/03_features/F14_생성기능_범위제외.md`, `docs/00_guide/DECISIONS.md`는 M7을 범위 제외로 둔다. 이 계약은 더 나중의 범위 제외를 따른다. M7은 켜고 끌 수 있는 출시 옵션이 아니다.

## 선택

M4 WASM은 선택이다. 문서 구조 검사가 필요한 화면에서만 쓰고, WASM을 쓸 수 없으면 작성 화면을 막지 않고 서버 검증으로 이어간다. WASM이 없어도 공개 출시를 막지 않는다. 브라우저 결과만으로 최종 검증을 생략하지 않는다.

Go 배포 도구는 필요가 생기기 전까지 선택이며 이 범위 계약의 필수 항목이 아니다.

## 예산·도메인·호스팅

월 비용, 도메인, 서버 사양은 미정이다. 0원으로 두지 않는다. 가정으로 금액이나 도메인 이름을 만들지 않는다.

| 항목 | 현재 | 결정 시점 | 담당 |
|---|---|---|---|
| 월 예산 | 미정 | 구매 전. M6 | 사이트 소유자 |
| 도메인 | 미정 | 구매 전. M6 | 사이트 소유자 |
| 호스팅·서버 사양 | 미정 | 구매 전. M6 | 사이트 소유자 |

로컬 개발 주소 `127.0.0.1:4321`과 `127.0.0.1:5173`은 운영 도메인이 아니다.
