## 브라우저에서 본 동작

개발 서버는 `127.0.0.1:4321`이다. 개발 도구 막대는 개발 서버에만 보이며 빌드 HTML의 본문이 아니다.

| 확인 | 관측 |
|---|---|
| 360px 홈 | 문서 너비 360, 화면 너비 360. 메뉴를 열어도 360 |
| 360px 소개 | 문서 너비 360, 화면 너비 360. 현재 메뉴 글자는 소개. main은 1개 |
| 768px 홈 | 화면 너비 753, 문서 너비 753. 메뉴 버튼은 숨고 탐색은 보임 |
| 1280px 홈 | 화면 너비 1265, 문서 너비 1265. 메뉴 버튼은 숨고 탐색은 보임 |
| 메뉴 열기 | 좁은 화면에서 열리면 첫 링크에 포커스 |
| Escape | 홈과 소개 모두 메뉴가 닫히고 포커스가 메뉴 버튼으로 돌아옴 |
| 시작 링크 | `소개 보기`와 `예시 프로젝트 보기` 사이 간격 있음. 프로젝트 링크는 `#featured-project`로 이동 |
| 소개 빈 상태 | 지향, 도메인, 기술, GitHub와 연락이 준비 문장. 홈 예시를 경력으로 쓰지 않는다고 적음 |
| 긴 제목 | 경계 fixture는 공개 페이지에 없음. 같은 구성의 임시 문단은 높이 144, 너비 328로 줄바꿈되고 문서 너비는 360을 유지. 확인 후 삭제 |

768과 1280의 화면 너비가 지정 너비보다 작은 것은 브라우저 스크롤바가 차지한 값이다. 문서가 그 너비를 넘지는 않았다.
