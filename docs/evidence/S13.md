## 배치

이미지 16의 실제 데이터 경로는 `/var/lib/postgresql/data`다. named volume `datagrizzly_pg`의 Docker 내부 마운트는 `/var/lib/docker/volumes/datagrizzly_pg/_data`이고, 컨테이너에는 그 경로를 읽기·쓰기로 붙였다. 다른 서비스는 없다.

제한은 메모리 805306368바이트(768 MiB), CPU 1.0, `/dev/shm` 256 MiB다. `shared_buffers` 128MB가 기본 64MB shm에 들어가지 않아 shm만 키웠다.

엔진은 기존 Docker Desktop을 켠 것이다. 서버 28.3.2, WSL 메모리 4108931072바이트, CPU 4. S08에서 적어 둔 `.wslconfig`가 이번 시작에 적용됐다. 재설치와 볼륨 삭제는 하지 않았다.

## 디스크와 메모리

C: 여유는 23.58 GiB에서 21.51 GiB다. 15 GiB 하한보다 크다. 메모리 전체는 13.84 GiB이고, DB가 켜진 뒤 호스트 여유는 0.51 GiB다. 컨테이너 한도는 768 MiB지만 실제 사용은 16.5 MiB다. 여유를 줄인 쪽은 Docker Desktop과 WSL이다.
