# 출시 게이트

기능: 공개 전환 전에 막힌 항목을 출시 보류로 남긴다.
목적: 검증 스크립트가 있다는 것과 공개 배포가 끝났다는 것을 구분한다.
연관: `infra/ops/release-gate.mjs`, `evaluations/search/m5-04.json`.

모델이 꺼져 있는 것은 결함이 아니다. 예산 알림은 지출을 자동으로 멈추는 상한이 아니다.

아직 출시 완료가 아니다. 공개 도메인이 없다.

- 로컬 이미지 `datagrizzly-api:m6`와 `127.0.0.1:5000`에 올린 digest는 `sha256:b7f2cd348b51155d816c54b687a5b467e65feb874a2ab49766761886c711b005`다.
- 격리 복원은 `datagrizzly_m6restore`에서 확인한 뒤 그 데이터베이스만 지웠다. 덤프 파일은 C:에만 있었고 확인 후 삭제했다.
- 사용자 여정은 `http://127.0.0.1:8080`에서 끝났고, TLS 확인 주소는 `https://127.0.0.1:8443/actuator/health`다. 둘 다 공개 URL이 아니다.
- 릴리스 표시는 `f55f9a3d-6bb6-4cef-8ff5-2b18f159eecc`다. 철회 뒤 검색에는 `m6-ops-check`가 나오지 않았다.
- 검색 지연, 메모리, 취약점 검사, SBOM은 측정하지 않았다.
