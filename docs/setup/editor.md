# S02 에디터 선택 기록

- 기록일: 2026-10-25
- 상태: **사용자 선택 관리로 생략**
- 프로젝트 경로: `C:\Dev\sideproject\My_Web`

사용자는 VS Code와 Cursor를 필요에 따라 자유롭게 실행해 사용한다. 프로젝트 문서에서는 특정 IDE 하나를 강제하지 않는다.

이번 단계에서는 다음 작업을 수행하지 않았다.

- IDE 설치·제거·업데이트
- 확장 설치·제거
- 전역 또는 프로젝트 설정 변경
- 기본 터미널 변경
- Git 초기화·작성자 설정·커밋·원격 연결

파일 인코딩·줄바꿈·프로젝트별 확장은 실제 저장소와 코드가 생성되는 시점에 해당 도구 설정과 함께 검증한다. 동시에 여러 IDE에서 대형 인덱싱이나 개발 서버를 실행해 자원을 중복 사용하지 않는 것은 사용자가 관리한다.

다음 실행 가능 태스크는 S05 버전표 확인이다. S03·S04 Git 작업은 사용자가 직접 설정할 때까지 보류한다.
